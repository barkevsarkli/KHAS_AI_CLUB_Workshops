### How to use the notebooks
1. Click **Open in Colab** for the project.
2. **File → Save a copy in Drive**, so your changes are kept.
3. **Runtime → Change runtime type → T4 GPU**.
4. Run the cells from top to bottom with **Shift + Enter**.
5. Cells marked **✏️ Your turn** have `TODO` blanks: we fill them in together during the workshop.
6. Stuck? Each notebook ends with a **🔑 Solutions** section. Run the solution for your step, then carry on.
